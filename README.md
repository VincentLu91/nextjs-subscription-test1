# AI Image & Content Generation Platform

A full-stack application for generating and transforming e-commerce visual content using AI image and video models.

## Features

- Generate and edit product images with AI
- Generate short-form product videos from images
- Create e-commerce visual assets through web-based workflows
- Store generated media and application data using Supabase

## Tech Stack

- Next.js / React
- Supabase
- Nano Banana 2
- Veo 3.1

## Project Status

This repository is maintained as a portfolio project demonstrating full-stack AI image and video generation workflows.
